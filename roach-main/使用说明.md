# 蟑螂 · 简体中文版

双击本文件夹里的 `index.html` 即可开始，无需联网、安装依赖或启动服务器。请使用支持 WebGL 2 的现代浏览器（如 Chrome、Edge）。

保留整个文件夹，尤其是 `local-pages.js`、`vendor`、`js`、`css`，不要只复制 HTML 文件。

首页进入游戏后，选择镊子并点击活蟑螂，即可进入标本室；点击左上角“返回”回到游戏。`game.html` 和 `specimen-lab.html` 也可单独打开。

第一阶段电脑版：普通左键使用当前工具；按住空格键并用左键拖动，或按住鼠标中键拖动，可移动画面。松开空格会停止左键拖动画面，需重新按下左键才会使用工具。右键不移动画面，游戏区域不弹出浏览器右键菜单。手机端仍使用双指拖动画面。

原页面结构、动画、工具、捕捉、标本操作、第二阶段、结局与排名均保留。汉化包括静态文案、动态提示、来信、部位名称及无障碍标签，字体使用本机中文字体。

## 本地加载说明

`vendor` 保存原项目已经使用的 Three.js **0.170.0** 及其两个插件，没有引入新框架或新依赖。原始模块文件和 MIT 许可证一并保留；`.local.js` 为可直接从本地文件加载的普通脚本版本。

通过 `file://` 打开首页时，使用 `local-pages.js` 中的页面副本加载同源 iframe，避免本地文件之间的跨域限制。通过 HTTP 打开时，仍加载原来的两个 HTML 页面。

## 代码结构

- `game.html`：主游戏的页面骨架（界面元素），只有几十行
- `css/game.css`：主游戏样式
- `js/game/01-core.js` … `14-main.js`：主游戏脚本，按编号顺序用普通 `<script>` 加载（不是 ES 模块，所以双击打开也能运行）。各文件顶层的 `const`、`class`、`function` 在同一页面里互相可见，新增文件时注意在 `game.html` 里按依赖顺序插入
- `index.html`：首页，负责开场说明、蟑螂来信、镊子夹取和标本室切换
- `specimen-lab.html`：标本室（单文件）

只改 `js/`、`css/` 下的文件时，刷新页面即可生效，不需要重新生成。修改 `game.html`、`specimen-lab.html` 这两个 HTML 或 vendor 原始模块后，在本文件夹执行：

```text
python tools/build-local.py
```

该脚本只使用 Python 标准库，用于同步本地页面副本和普通脚本。日常玩游戏不需要 Python。

## 手机与真机调试

手机（主要用手指操作、屏幕短边 ≤ 600）自动用手机档：阴影改用 PCF 并隔帧更新，地面污渍贴图 512×768，尸体降面，尸体上限 200。活蟑螂数量和难度与电脑版相同。

在网址后面加参数（首页的参数会传给游戏，可以组合使用，如 `index.html?debug&dpr=1.25`）：

- `?debug`：屏幕下方显示帧率、最慢一帧、JS 耗时、draw call、三角形和当前画质
- `?q=low` / `?q=high`：强制手机档 / 电脑档
- `?dpr=1.25`：手机档像素比上限（默认 1.5）
- `?aa=0`：手机档关抗锯齿
- `?cc=0`：手机档甲壳去掉 clearcoat 高光
- `?safe=0,47,21,47`：在电脑上模拟刘海屏安全区（上,右,下,左，单位像素）

安卓点“开始”时会进入全屏并锁定横屏；iPhone 竖着拿时显示“请把手机横过来”并暂停。

## 自动实测（开发用）

`tools` 下是用本机 Chrome 无头运行的实测脚本，会真实点击游玩三个阶段并检查性能和排版，截图写到 `tools/out`。玩游戏不需要它们。

```text
cd tools
npm install          # 只装 playwright-core，不下载浏览器
npm test             # 全部跑一遍，约 6 分钟
node run-all.cjs round2   # 只跑名字含 round2 的脚本
```

默认使用 `C:/Program Files/Google/Chrome/Application/chrome.exe`，其他位置用环境变量 `CHROME_PATH` 指定。

`test-mobile.cjs` 模拟手机横屏（安卓 915×412、iPhone 844×390，触屏，CPU 降速 4 倍），记录各场景的 draw call、三角形和每帧耗时，结果写到 `tools/out/mobile-<设备>.json`。把某次结果复制成 `mobile-<设备>.base.json` 当基线，之后运行会打印对比。它测不到手机 GPU，真机数字请用 `?debug` 面板看。
